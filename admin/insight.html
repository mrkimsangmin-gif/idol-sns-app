📌 인사이트 글 작성 & 업로드 워크플로우

  1. 글 작성: Claude Code에서 GUIDE_v3.md 프로세스로 글 작성 (5단계)
  2. aimcontents.com 업로드: 완성된 .md 파일을 이 관리자 페이지에서 불러오기 → 발행
  3. 2~3일 후 네이버 블로그 발행: 같은 글을 네이버 블로그에 올림
  4. 네이버 블로그에 유입 링크 삽입: 글 하단에 "원문 보기: https://aimcontents.com/insight/post.html?slug=xxx" 링크 추가

💡 네이버 블로그 → aimcontents.com 유입 전략

  1. aimcontents.com에 먼저 발행 (2~3일 선행)
  2. 네이버 블로그에 같은 내용을 올리되, 글 하단에 "더 많은 데이터와 인사이트 → aimcontents.com" CTA 삽입
  3. 네이버 블로그 제목에 SEO 키워드 포함 (네이버 검색 노출용)
  4. 네이버 블로그 글에 aimcontents.com 인사이트 글의 고유 URL을 링크로 삽입
  5. 구글 검색 콘솔에 aimcontents.com/insight/index_insight.html sitemap 제출

🔗 고유 URL 형식

각 인사이트 글은 아래 형식의 고유 URL을 가집니다:
https://aimcontents.com/insight/post.html?slug={슬러그}

이 URL을 네이버 블로그 글 하단에 삽입하면, 독자가 클릭하여 aimcontents.com으로 유입됩니다.
